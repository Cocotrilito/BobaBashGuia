# Guía Boba Bash Quito

Guía en español para que participantes de cualquier nivel creen y envíen una página web antes de Boba Bash Quito 2026.

## Estructura

- `dist/`: sitio estático publicado.
- `starter/`: archivos editables de la plantilla inicial.
- `.github/workflows/pages.yml`: despliegue automático en GitHub Pages.



Formulario oficial: <https://bash.hackclub.com/submit>
